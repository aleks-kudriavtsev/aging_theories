# Следующие контрольные точки

Версия 0.7 решает задачу запуска и безопасного воспроизведения исторической модели, а не закрывает клиническую валидацию.

1. **Независимая калибровка.** До извлечения исходов новой когорты зафиксировать SAP: популяция, исход, горизонт, преобразования, сравниваемые панели, обработка пропусков и метрики. Уже просмотренный NHANES2003–2004 не выдавать за новую независимую проверку. При недостаточной поддержке наблюдением горизонт не публиковать.
2. **Исходы по причинам.** Разделить смешанные ICD-группы, проверить взаимоисключение и контрольные суммы; сохранить инфекции, внешние и неизвестные причины как конкурирующие события. Не распределять общий риск по долям WHO.
3. **Россия и Германия.** Получить разрешённые индивидуальные данные/представительные калибровочные данные. До внешней проверки не снимать блокировки стран. Смена подписи US на RU не является рекалибровкой.
4. **Передача литературных доказательств.** Импортировать неизменяемый итоговый snapshot PR115; проверить источник, контекст и независимость когорт. Семантическое одобрение моделью не заменяет экспертную проверку.
5. **Метод измерения.** Сравнение собственной TRFIA с методами обучающих данных: смещение, воспроизводимость, пределы измерения и интерференции. До оценки переноса измерений не подставлять концентрации разных платформ автоматически.
6. **Клинический продукт.** Определить intended use и действие по результату; затем проспективная полезность, оценка безопасности и необходимые разрешения. До этого `clinical_use_ready=false`.

Для каждой точки нужен проверяемый артефакт: протокол, версия данных, код, журнал качества и отчёт с отрицательными результатами и неопределённостью. Число тестов ПО не подменяет эти критерии.
