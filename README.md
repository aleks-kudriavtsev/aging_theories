# aging_theories

## Mortality Workbench 0.7

Локальная исследовательская система: измерения → проверка единиц и применимости → расчёт по зафиксированной модели → HTML/JSON. **Не клинический калькулятор.**

```bash
python3 -m research.mortality.workbench doctor
python3 -m research.mortality.workbench serve
```

Открыть `http://127.0.0.1:8765`. [Установка, wheel, формат входа и пакетный расчёт](WORKBENCH_START_RU.md).

Приложение воспроизводит исторический US all-cause benchmark: 40–79 лет, горизонты 1/5/10 лет. Исход включает инфекции и внешние причины. Калибровки RU/DE/современных США, 20-летнего и cause-specific прогноза нет. Численная исправность не подтверждает клиническую точность.

Версия приложения 0.7.0 не переобучает модель 0.6_reader_corrected. Старый NHANES04-пакет сохранён отдельно. В 0.6 исправлено чтение точных нулей XPORT и выполнен повторный анализ уже просмотренной выборки; он не является новой независимой валидацией.

## Проверки

```bash
python3 -S -m unittest discover -s tests -p 'test_workbench*.py' -v
# Полный научный набор с исходниками:
GHE_SOURCE_DIR=WHO_SOURCE NHANES_SOURCE_DIR=NHANES_SOURCE NHANES_RESULT_DIR=OUTPUT04 \
  python3 -m unittest discover -s tests -v
```

Локально в итерации07: 245 тестов без пропусков. Автоматический GitHub workflow запускает автономное подмножество и проверку wheel, не скачивает данные участников. Без источников интеграционные тесты имеют skipped, что не равно полному прогону. Новые прогнозные метрики/клиническая валидация в07 не заявляются.

Код и авторские материалы следуют лицензии репозитория. Внешние источники сохраняют свои права; анализ не означает одобрение WHO/CDC. Не коммитить персональные измерения и отчёты. [Следующие научные контрольные точки](docs/DEVELOPMENT_GATES_RU.md).
