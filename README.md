# aging_theories

## Mortality RU–DE–US: evidence and prediction research

Исследование неинфекционных причин смерти, количественных биомаркеров и совместной модели абсолютного риска для России, Германии и США.

**Итерация 04 · 9 сентября 2026. Исследовательский прототип, не клинически валидированный калькулятор.**

### Текущий результат: обученный эталон общей смертности

NHANES 1999–2002: обучение на 4552 участниках; NHANES 2003–2004: временная проверка на 2384 участниках, 395 смертей за 10 лет, возраст 40–79. AUC рутинной клинико-лабораторной модели 0,8623; с NT-proBNP, hs-cTnT и цистатином C — 0,8716. Условный интервал добавочного AUC включает ноль; калибровка несовершенна, особенно у женщин. Клинический контроль без анализов явно отмечен как post hoc.

Это **общая смертность, включая инфекции и внешние причины**, а не завершённая модель целевого неинфекционного исхода. Исторические коэффициенты США не применяются к России/Германии или современным клиническим решениям. Горизонты 1/5/10 лет; 20 лет заблокированы. Все 95 локальных тестов выполнены без пропусков с исходниками WHO/NHANES; программные проверки не равны клинической валидации.

### Итерация 03 — сопоставимая база смертности

Получена сопоставимая база WHO GHE: оценки за 2021 год, выпуск 2024. Построены исходные NCD-топ-20 и отдельные топ-20 внутри 62 явно совместимых групп для каждой страны. Смешанные категории с инфекциями/внешними причинами не обнулены; для совместимых групп приведены условные границы ранга. Это ещё не окончательный строгий топ-20 всех естественных неинфекционных смертей.

Полные выгрузки пола/возраста и 2019/2021, исходный NCD-рейтинг и Excel включены в сопровождающий архив итерации 03. Машинные выгрузки смертности воспроизводятся командой ниже; оригинальные WHO XLSX/PDF в репозиторий не включены.

```bash
# WHO-парсер: Python >=3.10, стандартная библиотека.
python -m research.mortality.ghe2021 --sources /path/to/official_sources --out /path/to/results
# NHANES: зависимости и получение источников описаны в nhanes04/README.md.
python -m research.mortality.nhanes_benchmark --source NHANES_SOURCE --out OUTPUT --replicates 300
python -m research.mortality.clinical_sensitivity --source NHANES_SOURCE --out OUTPUT
GHE_SOURCE_DIR=WHO_SOURCE NHANES_SOURCE_DIR=NHANES_SOURCE NHANES_RESULT_DIR=OUTPUT \
  python -m unittest discover -s tests -v
```

Исходные имена и SHA-256 WHO зафиксированы в source_manifest.json. Изменение исходника останавливает расчёт до пересмотра версии. Workflow `.github/workflows/mortality-source-fetch.yml` предназначен только для ограниченного чтения публичных источников; расписания и автоматической записи данных в main нет. Аналогичный ограниченный workflow NHANES — `.github/workflows/mortality-nhanes-fetch.yml`.

**Историческая проверка 03:** все 60 тестов (37 прежних + 23 новых) выполнены локально с реальными WHO-файлами, без пропусков. Без исходников интеграционные тесты помечаются как skipped; это не полный успешный прогон. Актуальная проверка 04 включает 95 тестов и обе базы.

**Открытые ограничения:** модели WHO не подменяют первичную национальную статистику. Российская детальная национальная таблица не получена. Строгая очистка смешанных групп не закончена. Обучен только исторический US all-cause benchmark; cause-specific коэффициентов по 33 причинам и RU/DE калибровки нет. Матрица 33 причин отражает готовность проекта, не отсутствие моделей в мировой литературе. Прошедшая временная проверка не делает индивидуальные проценты пригодными для клинических решений.
