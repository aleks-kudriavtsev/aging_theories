# aging_theories

## Mortality RU–DE–US: evidence and prediction research

Исследование неинфекционных причин смерти, количественных биомаркеров и совместной модели абсолютного риска для России, Германии и США.

**Первая итерация: 9 сентября 2026. Исследовательская заготовка, не клинически валидированный калькулятор.**

- [Результаты первой итерации и научный протокол](research/mortality/REPORT_RU.md)
- [Первичный срез национальной смертности — JSON, не полный топ-20](research/mortality/mortality_snapshot.json)
- [Количественные эффекты и метрики из первоисточников](research/mortality/evidence.json)
- [Вычислительные примитивы: CKD-EPI 2021 и competing-risk CIF](research/mortality/engine.py)
- [Программные тесты](tests/test_mortality.py)

```bash
python -m unittest discover -s tests -v
```

Python >=3.10, стандартная библиотека. На первой итерации локально прошли 18 тестов. Они проверяют реализацию формул, а не клиническую точность.

**Открытые ограничения:** полный сопоставимый топ-20 трёх стран ещё не получен; российские национальные детальные значения не подтверждены первоисточником; индивидуальные когортные данные и обученные коэффициенты отсутствуют. Никакие индивидуальные проценты смертности по панели биомаркеров пока не выдаются.

Код и авторские материалы следуют лицензии репозитория. Права на внешние публикации и исходные массивы данных остаются у их правообладателей; лицензия репозитория не распространяется на них автоматически.
