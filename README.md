# aging_theories

## Mortality RU–DE–US: evidence and prediction research

Исследование неинфекционных причин смерти, количественных биомаркеров и совместной модели абсолютного риска для России, Германии и США.

**Итерация 03 · 9 сентября 2026. Исследовательский прототип, не клинически валидированный калькулятор.**

### Текущий результат

Получена сопоставимая база WHO GHE: оценки за 2021 год, выпуск 2024. Построены исходные NCD-топ-20 и отдельные топ-20 внутри 62 явно совместимых групп для каждой страны. Смешанные категории с инфекциями/внешними причинами не обнулены; для совместимых групп приведены условные границы ранга. Это ещё не окончательный строгий топ-20 всех естественных неинфекционных смертей.

Полные выгрузки пола/возраста и 2019/2021, исходный NCD-рейтинг и Excel включены в сопровождающий архив итерации. Машинные выгрузки смертности воспроизводятся командой ниже; оригинальные WHO XLSX/PDF в репозиторий не включены.

```bash
# Python >=3.10, стандартная библиотека.
python -m research.mortality.ghe2021 --sources /path/to/official_sources --out /path/to/results
GHE_SOURCE_DIR=/path/to/official_sources python -m unittest discover -s tests -v
```

Исходные имена и SHA-256 зафиксированы в source_manifest.json. Изменение исходника останавливает расчёт до пересмотра версии. Workflow `.github/workflows/mortality-source-fetch.yml` предназначен только для ограниченного чтения публичных источников; расписания и автоматической записи данных в main нет.

**Проверка:** все 60 тестов (37 прежних + 23 новых) выполнены локально с реальными WHO-файлами, без пропусков. Без файлов пять интеграционных тестов требуют `GHE_SOURCE_DIR` и помечаются как skipped. Это программная проверка, не клиническая валидация.

**Открытые ограничения:** модели WHO не подменяют первичную национальную статистику. Российская детальная национальная таблица не получена. Строгая очистка смешанных групп не закончена. Индивидуальные когортные данные и обученные коэффициенты смертности отсутствуют; проценты риска по биомаркерам не выдаются. Матрица 33 причин отражает текущую готовность проекта, не отсутствие моделей в мировой литературе.
