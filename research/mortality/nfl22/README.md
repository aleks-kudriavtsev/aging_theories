## Результат

Сравнение: raw frozen → cross-fitted calibration-only → cross-fitted calibration+log2NfL. Пять разбиений по целым PSU, без outcome-driven распределения. Для каждого участника обновление обучается на других PSU. Основной контраст отделяет вклад NfL от изменения общей калибровки.

|---|---:|---:|---:|
| Frozen |0,795056|0,023613|3,6949%|
| Recalibration OOF |0,780164|0,023072|2,4142%|
| NfL OOF |0,771448|0,023397|2,3784%|

Наблюдаемая взвешенная смертность2,3974%. Добавление NfL к recalibration-only: ΔBrier=+0,00032470; условный95%-ный интервал+0,00007027…+0,00055958. ΔAUC=−0,0087163; интервал−0,0258059…+0,0053533. Уверенное улучшение не получено. Условные интервалы1000rescaled-PSU повторов фиксируют уже построенные OOF-прогнозы и НЕ учитывают неопределённость обучения/выбора разбиений. Только37смертей; это не доказательство отсутствия общей прогностической/неврологической ценности NfL.

Это внутренняя оценка расширения на ранее использованном в программе цикле, не новая независимая внешняя валидация. Смерти от всех причин включены; отдельный NfL-прогноз смерти от деменции не обучался.

Сохранены14target-assay строк (включая разные IL6/TNFпанели и неуточнённую NPPB-форму). Это не40независимых людей. GFAP нижеLOD39/40; не более одного образца проходит совместный QC четырёх белков в любой из16комбинаций IL6/TNF assays. Критерий:NPX≥LOD и оба флагаPASS; это не подтверждение LOQ.

В полученных таблицах нет смертностного наблюдения и полного expanded13профиля. NPX не превращается вpg/mL, OlinkID не усредняются, рецепторы не заменяют цитокины, NPPB не объявляется специфическим NT-proBNP. Записи используются для анализа пригодности данных, не искусственного обучения.

## Воспроизведение

```bash
python -m research.mortality.nfl22.analyze --source OFFICIAL_CDC_INPUTS --out NEW_RESULTS
python -m research.mortality.nfl22.joint_audit --archive olink_raw.zip --out NEW_QC
NFL22_SOURCE=OFFICIAL_CDC_INPUTS JOINT22_ARCHIVE=olink_raw.zip python -m unittest discover -s tests -p test_nfl22.py -v
```

Численный модуль требует numpy/pandas/scipy/scikit-learn и прежние модули из базовой ветки. FrozenJSON самодостаточен; parentархив опционален для дополнительной структурной сверки. Без parentа метаданные проверки это отражают, численные результаты не меняются. Полные агрегированные CSV, источник/манифесты и развёрнутый научный отчёт передаются в Mortality_NfL_Joint22.zip; индивидуальные данные не перераспространяются.
