# Итерация 11. Индивидуальные биомаркеры и детализация причин смерти

**10 сентября 2026. Завершён ретроспективный аудит пригодности индивидуальных данных и реализован контракт наблюдаемых исходов. Новая модель в этой итерации не обучалась.**

## 1. Результат задачи

Собрана единая локальная аналитическая таблица шести уже исследовавшихся циклов NHANES1999–2010: **17 629 участников40–79 лет с доступными исходами**, из них **15 273 с полным клинико-лабораторным профилем**. Для каждого участника исход связан с его анализами через SEQN с проверкой один-к-одному. В GitHub и поставке находятся только код, агрегаты и отпечатки файлов, не индивидуальные записи.

Публичная linkage позволяет использовать девять именованных групп причин плюс остаточную группу, а не только три выхода модели09. Неизвестная причина сохраняется отдельным состоянием смерти. Созданы таблицы числа событий по причине, циклу, полу, возрасту, горизонту и полноте профиля. Получен проверяемый ответ, какие конкретные модели можно планировать по открытым данным и где нужен более подробный код исхода.

## 4. Какие диагнозы открытая linkage не различает

В публичном словаре2019 UCOD_LEADING получен укрупнением UCOD_113 [1–3].

| Задача | Возможность в1999–2014 | Причина ограничения |
|---|---|---|
|Цереброваскулярная смерть I60–I69|Выделяется:005|Ишемический инсульт I63 отдельно не выделяется|
|Болезнь Альцгеймера G30|Выделяется:006|Не равнозначна всем деменциям|
|ИБС I20–I25|Не выделяется|001 включает и другие болезни сердца|
|ХБП N18 как первоначальная причина|Не выделяется|009 включает N00–N07,N17–N19,N25–N27|
|Рак лёгкого C33–C34|Не выделяется|002 объединяет все C00–C97|
|ХОБЛ J44|Не выделяется|003 включает J40–J47, в том числе астму|
|Все внешние причины|Не выделяются целиком|004 означает только несчастные случаи; другие внешние причины входят в010|
|Вся естественная неинфекционная смерть|Не выделяется однозначно|Смешанные группы и остаток нельзя разделить по опубликованным кодам|

Важное уточнение заявки: **даже UCOD_113=100 недостаточно дляN18** — этот recode объединяет N17–N19. ИБС, напротив, можно получить из листовых059,060,062,063. Подытоги058/061 не должны считаться индивидуальными кодами. Более подробный словарь и исходный ICD нужны для точных подтипов [3].

Для группы гриппа/пневмонии в коде записан диапазонJ10–J18 именно из проверенной таблицы5.1 словаря2019, а не подставленный современный диапазон другого статистического продукта. Основной идентификатор этой работы — опубликованный UCOD_LEADING008. Таблицы разных версий кодирования требуют собственной проверки.

## 5. Двойной барьер следующей независимой проверки

**Причина смерти.** Для NHANES2015–2018 опубликованы только001,002,010; отсутствие005/009 там является укрупнением, а не нулём событий [1,2]. Следовательно, поздние циклы нельзя использовать как отрицательные метки инсульта или почечной смерти.

**Измерение.** Каталоги лабораторий2011–2012 и2013–2014 содержат основные компоненты рутинной панели, но CRP в них не указан [5,6]. Проверялись каталоги, не индивидуальные записи этих циклов. Нельзя считать отсутствие CRP обычным случайным пропуском и проверять прежнюю M1, проставив медиану всем участникам.

Вывод для следующего протокола: заранее обучить отдельную панель безCRP на доступных ранее изученных циклах, зафиксировать коэффициенты и только после этого открывать исходы нового проверочного цикла. CRP остаётся дополнительным модулем, когда он действительно измерен. Перед загрузкой проверяется и метод/единицы остальных анализов. Роль непрерывного исхода/цензурирования задаётся после проверки длительности наблюдения; восьмилетний горизонт не переносится автоматически на2013–2014.

**В этой итерации исходы2011–2014 и2015–2018 не скачивались и не анализировались.** Их metadata-инспекция не объявлена новой клинической проверкой.

## 6. Изменения системы

`endpoint_contract11.py` разделяет известную смерть, неизвестную причину и живой статус; проверяет допустимые коды по циклу, запрещает вывод недоступного подтипа и проверяет совместимость требуемых анализов. Неверная кодировка и конфликт «живой+причина смерти» блокируются. Функция фиксированного горизонта не считает коротко наблюдавшегося живого отрицательным исходом. Проверка происхождения не разрешает смешивать public/restricted mortality linkages, но сама не предоставляет прав доступа.

`audit_endpoint_cohorts11.py` связывает файлы один-к-одному, проверяет отпечатки, собирает полный и неполный домены, контролирует суммы и выдаёт агрегаты. Условия старого отбора по архивным кардиобелкам сюда не переносятся. Веса объединения первых циклов защищены отдельными тестами.

Исторические модели04/06/08/09, их прогнозы и приложение не менялись. **Нового повышения AUC, независимой проверки или страновой калибровки эта итерация не заявляет.** Её результат — пригодный для выполнения план конкретных исходов с проверенным ресурсом событий и предотвращением ложной валидации на недоступных метках/анализах.

## 7. Подготовленный пакет получения подробных данных

В `endpoint11/DATA_ACCESS_PACKAGE_RU.md` находятся требования к полям, точные конечные точки, маршруты доступа и готовый текст первичного обращения. Для США приоритет — одобренная RDC linkage с достаточной детализацией; для Германии — запрос SHIP; для России — согласование с держателями ЭССЕ-РФ или другой продольной когорты; UK Biobank рассматривается отдельно как британская вспомогательная когорта. Публичные metadata не равны полученным индивидуальным данным. Организационная допустимость доступа и условия договора ещё не установлены; заявки не отправлены.

Подготовленная заявка не требует контактов или прямых идентификаторов участников. Для сотрудничества с российским/немецким центром возможен расчёт в его среде по единому коду и передача проверенных агрегатов, без экспорта индивидуальных записей. Наблюдательная национальная выборка не становится репрезентативной только из-за названия страны.
