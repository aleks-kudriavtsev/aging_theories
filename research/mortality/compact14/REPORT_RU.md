# Итерация 14: компактная панель и новая временная проверка

Дата: 10 сентября 2026. Числа ниже — собственные расчёты проекта, не опубликованные метрики CDC.

## Полученный результат

К клиническому профилю добавлены четыре лабораторных показателя: HbA1c, креатинин/расчётная СКФ, отношение альбумин/креатинин мочи (UACR) и альбумин сыворотки. На новом цикле NHANES2015–2016 компактная панель улучшила заранее выбранный основной критерий относительно клинической модели. Она остаётся исследовательским кандидатом, а не глобально оптимальной, клинически готовой или доказанно эквивалентной расширенной панели.

Четыре показателя означают минимум пять определений аналитов: для UACR отдельно измеряются альбумин и креатинин мочи. Анамнез, курение, давление и антропометрия остаются обязательными. Стоимость и экономия не измерялись.

## IPCW и численная проверка

Brier(h)=Σwᵢqᵢ(h)||one_hot(Yᵢ)−pᵢ(h)||²/Σwᵢ. q=1/G(T−) для смерти к горизонту,1/G(h−) для известного статуса на горизонте,0 при раннем цензурировании. Знаменатель и средний прогноз сохраняют всех участников. G — обратная взвешенная Kaplan–Meier внутри домена; при равных месяцах смерть предшествует административному цензурированию. Цензурирование точно на горизонте означает наблюдение через горизонт. G(3−)=0,9975336. Предполагается независимое цензурирование внутри анализируемого домена.

Выполнено1000 парных rescaled-PSU повторов, seed20260914: сначала ресэмплинг в3256 подходящих наблюдениях, затем выделение общего домена; G оценивается заново в каждом повторе. Все1000 основных оценок определены. Интервалы условны относительно фиксированных моделей и не учитывают обучение/выбор панели.

Независимая Aalen–Johansen оценка частот совпала с IPCW с максимальным расхождением1,55×10⁻¹⁵. Две реализации прогноза сопоставлены на **93504 вероятностях**, максимальное расхождение **2,78×10⁻¹⁶**. Проверены27новых файлов по SHA256 и79768ячеек двух способов чтения mortality.

**243 выбранных локальных теста прошли без ошибок/пропусков:**30 новых автономного расчёта,28 новых научных/интеграционных,92 Workbench,47 реестра доказательств и46 метода парных измерений. ## Воспроизведение и область использования

`compact_panel14.py` — точный исходный код обучения, его SHA записан в замороженной модели. `evaluate_compact14.py` и `ipcw14.py` — оценка после поправки. `replay_compact14.py` — строгий автономный расчёт; коэффициенты и предыдущий Workbench не меняются.

```bash
python3 -S -m research.mortality.replay_compact14 --demo --out synthetic14.json
python3 -S -m research.mortality.replay_compact14 input.json --out research_result.json
```

Для научного воспроизведения сначала запускается train с официальными1999–2010источниками: он создаёт локальные идентификаторы разработки для проверки непересечения. Новый timestamp обучения меняет общий SHA нового файла: численные параметры сверяются с замороженной версией; оценка опубликованных результатов выполняется с оригинальным замороженным JSON.

Полный набор агрегированных CSV, манифесты, Excel и расширенный ITERATION_14_RU.md находятся в сопровождающем архиве. Индивидуальные данные и идентификаторы не распространяются. В Git сохранены научный код, компактные результаты и протоколы. Default-приложение и конференционные тезисы не переключены.

Результат относится к исторической общей смертности США40–79лет,1/3года. Нет индивидуальных интервалов риска, клинической полезности, country-калибровки RU/DE,20лет или детального чисто неинфекционного исхода. Следующий подбор по уже просмотренному2015циклу будет разработкой новой версии, не новой независимой валидацией.
