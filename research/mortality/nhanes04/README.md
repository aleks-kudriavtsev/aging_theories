# NHANES mortality benchmark 0.4

**Historical US research benchmark only. No clinical use.** Endpoint: all-cause death, not exclusively natural noninfectious death. Baseline age 40-79; evaluated horizons 1/5/10 years; no extrapolation to 20 years or RU/DE.

## Published contents

- `model_bundle.json`: all five original models plus explicitly post-hoc clinical comparator. Shared preprocessing is at bundle root; attach it to each model before replay.
- `metrics.csv`: full original 5 models x 3 horizons.
- `clinical_sensitivity.csv`, `clinical_sensitivity_intervals.csv`: post-hoc no-laboratory comparator.
- `RESULTS_SUMMARY.json`: cohort sizes, key uncertainty bounds, subgroup calibration and test status.
- `SOURCE_DATA_SHA256.txt`: exact fingerprints of 45 data inputs; official URLs are generated by `.github/workflows/mortality-nhanes-fetch.yml`.

Full 89-file source manifest, full output tables and test log are in the accompanying downloadable research bundle. Raw person-level records are not republished. The original source retrieval artifact (run 34402543947, artifact 10124022673) has one-day retention. The workflow downloads public CDC inputs and the old repository snapshot, records checksums, and does not have repository-write permissions.

The original full manifest SHA-256 was `ca00b793ec44aa0f2bfa45f48b82d021a70297ed55cbe2a6d9c98bb788c019cf`. Fresh retrieval may produce different HTML/manifest hashes. Check all 45 data fingerprints against this version; do not silently accept a changed scientific dataset as the same run.

## Reproduce

Python with numpy, pandas, scipy, scikit-learn; tests additionally use statsmodels. Observed environment: Python 3.13.5, numpy 2.3.5, pandas 2.2.3, scipy 1.17.0, statsmodels 0.14.6. Full legacy GHE integration tests also require WHO source workbooks. Individual source data remain local; scripts export aggregates/model parameters, not participant rows.

```bash
python -m research.mortality.nhanes_benchmark --source SOURCE --out OUTPUT --replicates 300
python -m research.mortality.clinical_sensitivity --source SOURCE --out OUTPUT
GHE_SOURCE_DIR=WHO_SOURCE NHANES_SOURCE_DIR=SOURCE NHANES_RESULT_DIR=OUTPUT \
  python -m unittest discover -s tests -v
```

`SOURCE` must contain the source workflow's original `manifest.json` and all its files: `verify_sources` checks that full retrieval manifest. `SOURCE_DATA_SHA256.txt` is an additional permanent data-version check, not a substitute manifest.
