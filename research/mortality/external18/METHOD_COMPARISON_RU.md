# Парное сравнение лабораторных методов

Проект дизайна, 13.09.2026. Реальные парные результаты и прецизионность новых наборов не предоставлены. Числа размеров ниже — предлагаемые параметры пилота, не обязательный норматив и не выполненный эксперимент.

## Два разных направления

1. Перенос модели: первоочередно HbA1c, креатинин, UACR и альбумин; для полной панели дополнительно RDW/лейкоциты. Здесь важно сохранить значение измерения, которое поступает в уже обученную модель. Для сывороточного альбумина методический сдвиг и переход к плазме — разные вопросы.
2. Разработка аптасенсоров: TNF-α, IL-6, далее другие мишени по технологическому плану. Эти показатели не заменяют HbA1c или почечный блок, а пока составляют исследовательское расширение. Kd по BLI и сэндвич-связывание характеризуют распознавание, но не доказывают точность измерения эндогенного аналита или прогноз смерти.

## Последовательность

**А. Определение измеряемой величины.** Тот же аналит/молекулярная форма, единицы, материал и антикоагулянт. Не подменять NT-proBNP на BNP, TNF-α на его растворимый рецептор, относительные RFU/NPX на пг/мл. Отдельно документировать функциональные/неактивные формы и эпитопную специфичность. Опорный иммуноанализ — метод сравнения, не автоматически референсная процедура высшего порядка.

**Б. Прецизионность.** Предлагаемый расширенный дизайн для нового метода: не менее трёх концентрационных уровней, 20 дней × 2 запуска × 2 повторения для каждого выбранного лота и метода. Это 80 результатов на уровень/метод/лот, 240 на три уровня; два метода дают 480, ещё один лот удваивает объём. Дизайн основан на классической схеме EP05 [S8]; окончательные числа и критерии должны соответствовать ресурсу, intended use и выбранной редакции руководства. Материал должен быть стабилен на период исследования.

Модуль precision.py оценивает сбалансированную вложенную ANOVA: повторяемость, межзапусковую и междневную компоненты. Он не объединяет несколько лотов в одну компоненту и не даёт доверительных интервалов компонентов. Отрицательные оценки до усечения сохраняются. Минимум 2×2×2 в коде — лишь математическая поддержка, не достаточная валидация. Отношение дисперсий ошибок нового и опорного метода выдаётся отдельно для каждого уровня; единое λ для Deming автоматически не выбирается. Нужно проверить зависимость дисперсии от концентрации и корреляцию ошибок; при неоднородности нужен взвешенный/обобщённый метод.

**В. Парные нативные образцы.** Предлагаемый стартовый бюджет: 200 уникальных образцов, заранее разделённых по донорам на 100 для оценки сопоставления и 100 для независимой проверки. Это проект пилота, а не универсальное достаточное n. Итоговое n рассчитывать по ширине доверительных интервалов смещения/границ согласия, диапазону и intended use. Распределение должно покрывать клинически релевантный диапазон, а не только здоровых добровольцев. Разные аликвоты одного донора не попадают в обе группы. Слепая рандомизация порядка измерений, учёт дня/оператора/лота/разморозок. Если исследуются одновременно матрица и метод — нужен факторный дизайн, а не одно сравнение плазма-новый против сыворотка-старый.

**Г. Анализ.** Деминг либо обоснованная альтернатива, разности и границы согласия, зависимости от концентрации. Значения ниже LLOQ, интерференции и технические отказы учитываются отдельно. Правила обработки заранее задаются, а не подбираются для красивой корреляции. Поправку fit-части проверять на holdout; не применять вне исследованного диапазона. Поправка не вступает в действие в риск-модели автоматически. Уже реализован method_bridge13.py.

**Д. Перенос риска.** В разрешённых данных с полным клиническим профилем заменить только результаты реально парно измеренного аналита и пересчитать неизменную модель. Сравнить абсолютные сдвиги риска и калибровку; для данных с исходами — также Brier/AUC. Если есть только парные образцы без исходов, можно оценить расхождение прогнозов, но нельзя доказать их точность или клиническую полезность.

## Критерии до анализа

Задать допустимое смещение в единицах/процентах при клинически значимых концентрациях, целевой CV, диапазон, LLOQ и интерференции для конкретного intended use. Допустимое изменение прогноза смерти требует отдельного клинического обоснования; прежний инженерный порог1п.п. не является таким нормативом. Корреляция r сама по себе не устанавливает взаимозаменяемость.

Метаданные исследования: analyte, method_id/version, reagent lot, calibrator traceability, matrix, anticoagulant, collection/processing/storage intervals, number of freeze-thaw cycles, instrument/reader configuration, calibration curve and reportable range. По пациентским материалам нужны подтверждённое разрешение и безопасная локальная псевдонимизация.

## Команды

```bash
python -m research.mortality.external18.precision precision.json --out precision_result.json
python -m research.mortality.method_bridge13 metadata.json --pairs paired.csv --out comparison.json
```

Модули не изменяют clinical_use_ready и не создают страновую калибровку. Программа анализа не проводит физический эксперимент.
