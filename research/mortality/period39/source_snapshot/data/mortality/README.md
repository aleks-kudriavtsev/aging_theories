# Смертность по странам (США, Германия, Россия)

См. [`docs/12_cross_country_mortality.md`](../../docs/12_cross_country_mortality.md) для
полного описания источника, метода и находок.

| Файл | Содержание |
|------|------------|
| `mx_qx_usa_deu_rus.csv` | `country,sex,year,age,mx,qx,series` — США/DEU/RUS × М/Ж × 1950–2023 × возраст 0–100. Источник: UN WPP 2024 (`wpp2024` R-пакет, CC BY 3.0 IGO), `qx` посчитан из `mx` по стандартному допущению (`qx=1-exp(-mx)`). |
| `gompertz_fits_usa_deu_rus.csv` | Подгонка Гомпертца–Мейкема (`A`, `R0`, `beta`, `MRDT`) по возрасту 20–90, по десятилетиям 1960–2020, для каждой страны/пола. |

Пересобрать оба файла: `python tools/fetch_wpp_mortality.py && python analysis/gompertz/fit_crosscountry.py`.

Публичные, не персональные, лицензированные данные (CC BY 3.0 IGO) — коммитятся в
репозиторий как есть (в отличие от `data/raw/`, см. `.gitignore`).

## WHO: доли причин смерти (L1)

`python data/mortality/build_cause_fractions.py` без сетевых обращений читает локальные
архивы `who_mdb_raw/` и строит:

- `cause_fractions.csv` — 2019, USA/JPN/DEU/RUS × пол × возраст × семь групп из
  `data/literature/cause_weights.csv`;
- `icd10_mortality_list1_crosswalk.csv` — программно извлечённую Table 8 документации WHO,
  включая признак листа иерархии списка 101;
- `ill_defined_fractions.csv` — отдельно долю R00–R99 (код 1094 списка 101) по стране.

`python data/mortality/build_l1_endpoints.py` затем строит верхние 40 клинических L1
endpoint'ов для смертей в возрасте 40+ (оба пола):

- `l1_endpoint_fractions.csv` и `l1_endpoints.json` — доли по четырём странам и
  равновзвешенное среднее стран;
- сгенерированный L1-блок в `docs/article/framework_paper/nodes.csv`, без изменения его
  пятиколоночной схемы.

USA/JPN/DEU используют детальный список 104. Для России значение записывается только если
ICD-набор endpoint'а является точным объединением листьев списка 101; иначе российская доля
и четырёхстрановое среднее остаются пустыми/`null`, а ранжирование использует среднее только
по доступным странам. Это, в частности, не позволяет выдумать российские доли инфаркта,
сердечной недостаточности, ХОБЛ или цирроза из более широких строк списка 101.

Скрипт проверяет равенство суммы листьев all-cause числу для каждой ячейки и сумму долей,
равную единице. `inflammaging` не является взаимоисключающей первопричиной ICD и поэтому
сохраняется нулевой строкой; это явно печатается при сборке.

Важно: Annex 1 документации WHO показывает, что `Frmat=01` объединяет 85+ в `Deaths23`,
оставляя `Deaths24/Deaths25` пустыми. Поэтому у Германии и России последний интервал — 85+;
скрипт не интерпретирует отсутствующие 90–94 и 95+ как нулевую смертность.
