# Уточнения39 до численных результатов

Протоколc0a570e остаётся неизменным.72chaining checks означают72возрастно-половые
строки:2пола×36точных стартовых возрастов40…75. Проверяем каждый из двух
заявленных методов:144скалярных равенства. Это проверка математики, не144исхода
или независимых наблюдения. Стартa+5 должен оставаться≤80 для strict adapter.

Для UDD q=m/(1+.5m) допустим0≤m≤2. Верхний endpoint rounding sensitivity тоже
не должен превышать2; при превышении расчёт блокируется, а не обрезает q.
При m=2 допустим q=1 и survival=0. Из derivative≤1 на этом домене следует
заданный guard ширины rounding envelope≤h·1e−6. В данных возрасте40–89 этот
guard проверяется после расчёта, не используется для редактирования ставок.
Каждая ставка отдельно допускается в своём rounding interval; это внешний
прямоугольный набор допустимых ошибок, а не предположение об их вероятностной
независимости. Он не включает smoothing/model uncertainty исходной оценкиООН.

Выход всегда **provisional local-derived period reference**. Документированная
единица — annual deaths/person-year, и primary UN methodology подтверждает
определение central death rate. Однако originalRDA checksum и конкретный
численный package→CSV unit bridge не восстановлены. Нельзя превращать проверку
локальных hashes в утверждение о заново аутентифицированных officialUNq или
современных национальных clinical forecasts. Допущение о единицах явно входит
в трактовку результата. RawRDA/newcohort downloads не выполняются.

График строится только по агрегатным164ячейкам с теми же flags. Линии соединяют
целочисленные возрасты для показа; adapter не делает fractional-age interpolation.
Матplotlib — optional export dependency; основная таблица/CLI и unit tests —stdlib.
Визуализация не оценивает клиническую полезность панели или calibration пациента.

Периодный общепопуляционный ориентир не выделяет disease-free состояние и уже
содержит текущую смесь болезней/лечения/прочих рисков. Его нельзя просто прибавить
к смертности после диагноза из38. Для такого переноса нужна совместимая
репрезентативная riskfactor/state distribution и отдельная валидация.
